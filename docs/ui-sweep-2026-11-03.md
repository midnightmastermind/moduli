## Rubric

- **works** — did what its label says, no page error. `nothing` = the tap changed no DOM, URL or focus, opened nothing and sent nothing: a dead control.
- **reach** — on screen, hit-testable (nothing covers it), phone tap target ≥ 24px (✅ ≥ 32px), a touch path for anything hover-only, no sideways scroll.
- **a11y** — axe (wcag2a/aa/22aa) serious+critical = 0 inside what opened; labelled (icon buttons carry aria-label/title); Escape closes; focus returns.
- **clear** — the label says what it does, no jargon (occurrence/module/ids…, except the operations editor), an empty state says what to do next, a destructive action confirms or undoes; the area's common task in ≤ 3 taps.
- **fast** — tap → painted: menus ≤ 100 ms desktop / ≤ 250 ms phone at 4× CPU; scroll ≤ 150 ms/step median at 4×; no freeze > 3 s after rows show.

Marks: ✅ · 🛠 fixed (commit) · ⚠ left (why) · ✗ broken.
