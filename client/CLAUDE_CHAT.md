
**`0175` — the timed movements, shipped.** `Time 1/2/3` are number fields in SECONDS (`" sec"`,
5-second steps) — deliberately not the `duration` type, which renders hours+minutes and cannot say
45 seconds at all. Values are the plan's own: Planks *"3 sets of 1 minute"* → 60; Side Planks
*"3 sets of 30-45 seconds per side"* → **45, and that one is a choice rather than a reading** — the
plan gives a band, a prescription needs a figure, and the top of the band is the target. One value
in a catalog the user can edit. "Timed" is SELF-DESCRIBING (an option carrying a `Time 1`
prescription) so there is no marker field to keep in sync. Both live plank rows sit on the Thursday
TEMPLATE, so every column built from it inherits the swap.
